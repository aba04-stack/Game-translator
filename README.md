# RPGMTL v5.0 — Переводчик игр

Экспериментальный инструмент для извлечения, перевода и обратной вставки текстов в игры. Проект предоставляется «как есть»; перед обработкой оригинальной игры сделайте резервную копию.

## Запуск

Требуется Python 3.10+ (версию лучше проверить на вашей системе).

```bash
python -m pip install -r requirements.txt
python run.py
```

Для консольного режима доступен `cli.py`. Основные команды и параметры описаны в его справке:

```bash
python cli.py --help
```

Для AI-перевода нужен API-ключ одного из поддерживаемых провайдеров. Вводите ключ в настройках приложения или передавайте его через CLI; не добавляйте настоящие ключи в Git.

## Проверки

```bash
PYTHONPATH=. python -m pytest -q
```

Некоторые интеграционные и GUI-тесты требуют установленных зависимостей из `requirements.txt`.

## Статус

Это личный экспериментальный проект. Совместимость с конкретной игрой/движком и сохранность файлов нужно проверять на копии игры.
