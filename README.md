# Game Translator — ИИ-переводчик игр

Извлекает тексты из игры, переводит их через ИИ (OpenAI, Gemini, Claude, Groq, DeepSeek или локальный сервер),
проверяет результат и вставляет перевод обратно — с резервной копией оригинала и откатом.

Работают два интерфейса: окно (PyQt6) и командная строка.

> **Статус: НЕ релиз.** Основные риски потери данных закрыты и покрыты тестами, но проект **не проверялся на
> настоящих играх, с живыми API и на Windows** — см. [PROJECT_STATUS.md](PROJECT_STATUS.md), раздел
> «Что НЕ сделано».

## Движки

RPG Maker MV / MZ, RPG Maker VX / Ace, Ren'Py, Unity, Godot, TyranoBuilder, Kirikiri / KAG, Wolf RPG.
Проверка на синтетических мини-проектах и таблицах кодов; реальные игры по каждому движку ещё не прогонялись.

## Установка

Проверено на **Python 3.12** (`run.bat` заявляет 3.11+).

```bash
python -m pip install -r requirements.txt
python run.py            # окно; на Linux/macOS можно ./run.sh
```

## Командная строка

```bash
python cli.py extract   --game /путь/к/игре --output /путь/вывода
python cli.py translate --game /путь/к/игре --output /путь/вывода --provider claude --target-lang Russian
python cli.py polish    --game /путь/к/игре --output /путь/вывода --provider claude
python cli.py inject    --game /путь/к/игре --output /путь/вывода
python cli.py restore   --game /путь/к/игре                              # вернуть оригинал из резервной копии
python cli.py export    --output /путь/вывода --csv перевод.csv
python cli.py import    --output /путь/вывода --csv перевод.csv
python cli.py stats     --game /путь/к/игре --output /путь/вывода
```

Полный список параметров: `python cli.py --help` и docstring в начале `cli.py`.

**Ключ API** лучше передавать переменной окружения (ключ в `--api-key` виден в списке процессов и истории
оболочки). Порядок: `--api-key` → `RPGMTL_API_KEY` → `OPENAI_API_KEY` / `GEMINI_API_KEY` (или
`GOOGLE_API_KEY`) / `ANTHROPIC_API_KEY` / `GROQ_API_KEY` / `DEEPSEEK_API_KEY`. Для локального сервера
(LM Studio / Ollama) укажите `--base-url`, ключ не нужен.

**Проверка без денег и без сети:** `--provider mock` — весь конвейер отрабатывает офлайн (текст получает префикс
«[язык] », это не перевод).

**Коды возврата:** `0` успех · `1` ошибка выполнения · `2` ошибка использования (нет ключа, неверные аргументы) ·
`3` перевод завершён, но часть строк не переведена · `130` прервано (Ctrl+C: первое нажатие — мягкая остановка с
сохранением прогресса, второе — немедленный выход).

## Модели по умолчанию

Задаются в `ai_translator.DEFAULT_MODELS` (единый источник; любую можно переопределить в настройках или `--model`).
Сверено с официальной документацией провайдеров **2026-10-22**:

| Провайдер | По умолчанию | Примечание |
|---|---|---|
| Claude | `claude-haiku-5-5` | модели 5.x отвергают `temperature` ≠ значения по умолчанию — проект его не отправляет |
| Gemini | `gemini-3.6-flash` | `gemini-2.0-flash` закрыт 2026-06-01 |
| Groq | `openai/gpt-oss-20b` | Llama-модели закрыты 2026-08-16; поведение gpt-oss с проектом не проверялось |
| DeepSeek | `deepseek-flash` | актуальная модель из официального списка DeepSeek; legacy-имя `deepseek-v4-flash` выведено из обращения |
| OpenAI | `gpt-4o-mini` | **снимается 2027-01-14**; преемник не выбран — задайте модель вручную |

При запуске в логе появляется предупреждение, если выбранная модель закрыта или скоро будет закрыта.

## Что защищает ваши данные

- **Резервная копия оригинала** создаётся при первом Inject; «Восстановить оригинал» возвращает файлы
  байт-в-байт и честно сообщает, если часть не восстановилась.
- **Ручные правки не затираются.** Строки, набранные вручную, импортированные из CSV, одобренные или
  заблокированные, не перезаписываются ИИ-переводом, полировкой, глоссарием и авто-ремонтом кодов.
  В таблице «Строки» они подсвечены; правый клик — «Одобрить / Заблокировать / Снять защиту».
- **Состояние перевода** (`translation_state.json`) пишется атомарно, хранит резервную копию `.bak`; повреждённый
  файл уходит в карантин `*.corrupt-<время>` и не затирается молча.
- **QA-барьер перед Inject:** критические ошибки (потерянные escape-коды и т. п.) блокируют вставку; файл, который
  QA не смог прочитать, тоже блокирует (fail-closed).
- **Постоянные ошибки API** (неверный ключ, закрытая модель) останавливают перевод сразу, а не после часов повторов.

## Проверки GitHub Actions

- **Game Translator CI** запускается при push в `main` и рабочую ветку, а также для pull request в `main`. Он устанавливает зависимости, проверяет запуск CLI, компиляцию, весь набор офлайн-тестов и pyflakes. API-ключ для этого workflow не нужен.
- **DeepSeek Integration** запускается вручную из вкладки **Actions** на ветке `main`. Он отправляет один небольшой пакет из четырёх игровых строк модели `deepseek-flash`, проверяет перевод, плейсхолдеры, escape-коды, теги и символы, а затем выполняет Extract → Inject на временной RPG Maker MV-игре и сверяет JSON-структуру. Режим рассуждений отключён, вывод ограничен 384 токенами. Запрос оплачивается по действующему тарифу DeepSeek; см. [официальные цены](https://api-docs.deepseek.com/quick_start/pricing/).
- Чтобы запустить live-проверку после попадания workflow в `main`: **Actions → DeepSeek Integration → Run workflow → Run workflow**. В репозитории должен быть Secret `DEEPSEEK_API_KEY`. Workflow не запускается на pull request и выдаёт секрет только коду из `main`; вывод и сообщения об ошибках не содержат ключ.

## Разработка

```bash
python -m pip install -r requirements-dev.txt
QT_QPA_PLATFORM=offscreen python -m pytest tests -q                  # обычный порядок
QT_QPA_PLATFORM=offscreen python -m pytest tests -q --random-order   # ловит скрытые зависимости между тестами
python -m pyflakes $(git ls-files '*.py' | grep -v '^tests/')
```

Тесты изолированы: каждый получает пустую домашнюю папку (настройки, лог, Global TM) и не трогает ваши данные
(`tests/conftest.py`).

## Известные ограничения

Коротко (подробно — в [PROJECT_STATUS.md](PROJECT_STATUS.md)): не проверялись реальные пользовательские игры; live API smoke-тест добавлен, но требует ручного запуска и не выполняется автоматически. GUI
проверен offscreen-тестами, не визуально и не на Windows; сборка PyInstaller не запускалась; «Сохранить правки» в
окне и одновременный Translate могут перезаписать состояние друг друга; правка JSON-файлов вручную вне окна и CSV
не помечается как «ручная».
