# PatchLingo

PatchLingo помогает переводить игровые тексты на русский с помощью ИИ. Программа извлекает текст из игры, переводит его, позволяет проверить результат и вставляет перевод обратно.

Есть оконный интерфейс и командная строка.

## Поддерживаемые движки

RPG Maker MV / MZ, RPG Maker VX / Ace, Ren'Py, Unity, Godot, TyranoBuilder, Kirikiri / KAG и Wolf RPG.

## Как начать

**Windows:** откройте вкладку **Actions**, выберите **Windows Build** и скачайте артефакт `PatchLingo-Setup`. Распакуйте ZIP и запустите установщик.

**Из исходников:** установите Python 3.11 или новее, затем выполните:

```bash
python -m pip install -r requirements.txt
python run.py
```

## Перевод

Для перевода через облачный ИИ выберите провайдера и укажите его API-ключ в настройках. Поддерживаются OpenAI, Gemini, Claude, Groq и DeepSeek. Ключ нельзя публиковать или добавлять в репозиторий. Для локального сервера можно использовать LM Studio или Ollama.

## Перед началом

Проект ещё развивается и пока не проверен на всех типах реальных игр. Сначала сделайте копию игры и проверяйте перевод на ней.

Команды CLI, подробная настройка и инструкции для разработчиков собраны в [DEVELOPMENT.md](DEVELOPMENT.md).
