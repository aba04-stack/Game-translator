# PatchLingo

PatchLingo переводит игровые тексты на русский с помощью ИИ.

Программа извлекает текст из игры, помогает перевести его и возвращает перевод обратно. Оригинальные файлы можно восстановить.

## Поддерживаемые игры

RPG Maker MV / MZ, RPG Maker VX / Ace, Ren'Py, Unity, Godot, TyranoBuilder, Kirikiri / KAG и Wolf RPG.

## Установка в Windows

Откройте **Actions → Windows Build**, скачайте **PatchLingo-Setup**, распакуйте архив и запустите установщик.

Перед переводом проверьте программу на копии игры: проект ещё развивается, и совместимость со всеми играми не проверена.

Для технической информации см. [DEVELOPMENT.md](DEVELOPMENT.md).
